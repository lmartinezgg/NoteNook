Intelligent note syncing suite leverages context-aware organization and adaptive syncing algorithms for streamlined knowledge management.

With NoteNook, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/NoteNook.git`
2. `cd NoteNook`
3. Install in editable mode: `pip install -e .`

## Configuration

NoteNook is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
